## 一、三网优化到底优化了哪三条线

三条线各有对应的 AS 号，记不住名字就记 AS 号，商家页面写得再花，AS 号对不上就是没接。

| 运营商 | 精品线路 | AS 号 | 普通线路 | 实际差别 |
| --- | --- | --- | --- | --- |
| 电信 | CN2 GIA（全程）/ CN2 GT（半程） | AS4809 | 163 骨干 AS4134 | GIA 全程走专网，晚高峰丢包低；GT 只有一段走专网，拥挤时段同样掉速 |
| 联通 | AS9929 / AS10099（CUG） | AS9929、AS10099 | AS4837（169 网） | 精品网路由更短，4837 在晚间拥塞明显 |
| 移动 | CMI | AS58453 | 普通国际出口 | CMI 走香港—广州陆缆入境，移动用户延迟通常最低 |

市面上被叫做“伪三网优化”的方案，毛病集中在两处。一处是三条线只接了一条，通常是移动的 CMI，电信和联通去回程绕日本或美国，白天看着 40ms，晚上八点后跳到 200ms 以上。另一处是只优化回程，去程仍走普通 BGP，表现为上传慢、SSH 敲一个字母等半秒。

判断方法很简单：页面上有没有写出具体的 AS 号。只写“三网优化”“BGP 智能路由”“CN2 高速通道”而不给 AS 号的，按没接处理。

## 二、下单前把这三个问题问出去

问客服，不要问“你们是不是三网优化”，这句话得到的回答一定是“是”。要问的是三条独立的问题：

1. **电信回程走什么？** 是 CN2 GIA、CN2 GT，还是 163 普通骨干，分别对应 AS4809 和 AS4134。
2. **联通回程走什么？** 是 AS9929、AS10099，还是 AS4837。
3. **移动回程走什么？** 是 CMI 直连，还是绕香港本地其他运营商出海。

再加一句追问：**去程和回程是不是都做了优化？** 只优化单向的方案很常见，单向优化对下载党够用，对直播推流、网盘上传、远程桌面这类持续上行的场景就不够。

三条都答得出具体 AS 号，这家才值得继续看。答得含糊、或者把“我们用的是 BGP 多线”当答案的，直接跳过。

## 三、商家给的截图不算数，自己跑三件事

第三方测评和商家后台截图都只能当参考，机器到了自己手上才算数。三件事，半小时能做完：

**第一件，看回程经过哪些 AS。** 在机器上对你家的公网 IP 跑 `mtr` 或 `traceroute`，逐跳看 AS 号。看到 4809 说明走 CN2，看到 9929 或 10099 说明走联通精品网，看到 58453 说明走 CMI。全程都是国内 AS 加香港本地 AS、没有中途跳到美国日本的，才算真直连。

**第二件，三家宽带分别测。** 自己只有一条宽带就找朋友帮忙，或者用三网测速节点各跑一次。只测自己那家，等于只验证了三分之一。

**第三件，晚高峰复测。** 晚上 20:00 到 23:00 之间再跑一遍同样的命令。白天的延迟漂亮不代表晚上漂亮，三网优化的钱基本都花在这三个小时里。

延迟可以对着这个区间看：第三方测评里，三网直连的香港节点常见水平是深圳 10–20ms、上海 30–45ms、北京 40–60ms。某条线跑到 80ms 以上，基本可以怀疑绕路；同一台机器白天 40ms、晚上 180ms，说明这条线是挤在公网骨干上的。

## 四、端口带宽、月流量和“双向计费”

套餐页上那两个数字经常被误读。

**端口带宽是峰值，不是保证值。** 标 200Mbps 指的是这口子最高能跑到 200Mbps，机房整体拥塞时跑不满是正常的。真要跑满，得看商家有没有写“保证带宽”，绝大多数低价套餐不写。

**月流量通常是双向合计。** 标 800GB/月，指上行加下行总共 800GB，不是各 800GB。日常建站、SSH、API 调用、偶尔看看视频，800GB 很宽松；做直播推流、跑定时备份同步、挂下载任务，上行消耗很快，一个月吃满不稀奇。这类用途在选档时要把流量往上抬一档，或者干脆选不限流量但限速的方案。

## 五、原生 IP、机房 IP，以及会随时间衰减的纯净度

这两件事经常被混成一件。

**机房 IP** 指这段地址在风控库里被标记为 Hosting 或 Data Center。TikTok、部分流媒体、某些电商后台会直接拦这类段，表现是注册提示网络异常、登录要求反复验证。

**原生 IP** 指这段地址的 whois 归属地和机器所在地一致，查出来是香港。原生只解决“归属地看起来对不对”，不解决“这段地址干不干净”。

**纯净度会衰减。** 新分配的 IP 段干净，被前面用户拿去做过批量注册、发过垃圾邮件之后，评分就下来了。同一台机器用半年，体验可能比刚开通时差。所以选商家时值得确认一句：IP 被标记了能不能工单换，换要不要钱。能换的商家，长期持有的风险小很多。

还有一层：原生 IP 不等于住宅 IP。住宅 IP 是运营商分配给家庭宽带的那种段，机房里的机器拿不到，标着“住宅 IP”的产品实际是商家通过别的方式接进来的，价格和用途都不一样。做普通建站和中转，机房里的原生 IP 够用；做账号运营，才需要为住宅属性多付钱。

## 六、第一年便宜不代表第二年便宜

这是这类软文普遍不算的一笔账。把两年拆开算：

**第一年实际支出** = 首期价（标价减去优惠码）＋ 可能的一次性费用。
**第二年实际支出** = 续费价 × 计费周期。续费价通常等于标价，优惠码只作用于首次付款。

看到“年付 7 折”的时候，先确认三件事：这个码的有效期到哪天、是不是只对新购生效、续费时按哪个价。第三方整理的优惠码页面经常不写截止日期，一个去年中秋活动的码能挂一整年，点进去结算页显示无效，白折腾。

还有一条更实际的做法：不确定要不要长期用，先月付。月付比年付贵出来的那部分，本质上是为“随时能走”付的保险费。一台机器用了一个月发现晚高峰不稳，月付的损失是一个月，年付的损失是十一个月。

## 七、按用途选档：哪一档够用，哪一档是浪费

配置表上的核数和内存好比较，难的是知道自己的用途落在哪一档。按场景对一遍：

| 用途 | 优先看的参数 | 最容易买错的地方 | 建议 |
| --- | --- | --- | --- |
| 个人博客、小后台、API 服务 | 内存 ≥1GB、SSD、月流量几百 GB | 被大带宽数字吸引，多花钱在跑不满的端口上 | 入门档足够，1 核 1G 是常见起点 |
| 中转、代理、SSH 跳板 | 三网回程质量，带宽够用即可 | 买了大带宽但线路绕，晚高峰照样卡 | 选最便宜的档，把钱花在线路上 |
| TikTok、港区流媒体 | 原生 IP、端口带宽 100Mbps 以上 | 把机房 IP 当住宅 IP，注册就碰壁 | 先测 IP 再决定是否年付 |

## 八、哪些情况这台机器解决不了

**需要高防 DDoS 的。** 三网优化套餐基本不带高防，被打了就是被打，清洗要另买。做暴露端口的业务，先确认商家有没有高防产品线。

**需要 500Mbps 以上持续大带宽的。** 香港机房到大陆的国际带宽成本摆在那里，低价套餐给不出这个量。转码、大文件分发、CDN 回源这类用途，该看独立服务器或专门的带宽型产品。

**需要 Windows 授权的。** 多数香港 VPS 默认 Linux，装 Windows 要自己带授权，部分商家不提供。跑特定 Windows 软件的，下单前问清楚。

**想买完就不管的。** 线路会调整，IP 会变脏，机房会搬迁。三网优化是买当下的路由质量，不是买永久承诺。愿意每隔几个月复测一次的人，才适合长期持有。
